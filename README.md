# OrbitAi

**Description:**  
OrbitAi is an AI chat model inspired by ChatGPT, Gemini, and Claude. It can answer questions in multiple languages (English, Bangla, Hindi), provide concise replies, and politely handle image requests by suggesting other AI tools such as ChatGPT, Gemini, or Grok.  

**Live Demo:**  
[https://orbitai-two.vercel.app/](https://orbitai-two.vercel.app/)  

**Features:**  
- **Multilingual support:** Responds in the same language as the user (English, Bangla, Hindi).  
- **Short and concise answers:** Ideal 1-3 sentence replies.  
- **AI agent OrbitAi behavior:**
  - Replies to name queries: "My name is OrbitAi."  
  - Handles image requests politely: "I cannot generate images, but you can use ChatGPT/Gemini/Grok for that."  
- **Responsive and lightweight chat interface** suitable for desktop and mobile.
